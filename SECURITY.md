# Security

The bot's code is closed source, but its behavior is public and its infrastructure is reachable, so security reports are welcome and taken seriously.

**Please do not open a public issue for a vulnerability.** Use [private vulnerability reporting](https://github.com/Phobetore/SirrMizan/security/advisories/new) instead. It is the same repository, but the report stays visible only to you and the maintainer until a fix ships, and GitHub carries the advisory, the disclosure timeline and your credit line without either of us having to organise it. The same form is on the **Security** tab, under *Report a vulnerability*.

If you would rather not go through GitHub, a private message to the maintainer on the [support server](https://discord.gg/wAbMMPnwbg) reaches the same person.

What helps: what you found, how to reproduce it, and what you think the impact is. You will get an acknowledgement, a fix or a reasoned answer, and credit if you want it.

Scope worth probing: the bot's command handling, the website (sirrmizan.threatchaos.org), and the public status endpoints. Out of scope: volumetric denial of service, and anything requiring physical access.
