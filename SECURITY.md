# Security

The bot's code is closed source, but its behavior is public and its infrastructure is reachable, so security reports are welcome and taken seriously.

**Please do not open a public issue for a vulnerability.** Instead, send a private message to the maintainer on the [support server](https://discord.gg/wAbMMPnwbg).

What helps: what you found, how to reproduce it, and what you think the impact is. You will get an acknowledgement, a fix or a reasoned answer, and credit here if you want it.

Scope worth probing: the bot's command handling, the website (sirrmizan.threatchaos.org), and the public status endpoints. Out of scope: volumetric denial of service, and anything requiring physical access.
